### 1. 그로들 — 프론트엔드 리드

2024.10 ~ 재직 중 | 정규직 | 프론트엔드 개발

#### 1.1. FE 팀 리딩 및 서비스 운영 (2024.10 ~ 2026.11)

커머스 SaaS의 웹, 앱, 크롬 익스텐션 FE를 총괄하며 팀을 리드하고 있습니다.

**리드, 협업**

- 주간 FE 미팅 운영, E2E, Vite 전환 경험 사내 공유
- 디자인 시스템 구축, 신규 및 변경 화면 전면 적용
- React Native 앱 빌드, 배포를 맡아 fastlane으로 자동화

**운영, 제품**

- 브랜치 전략을 trunk-based로 단순화하고, 릴리즈 노트 자동화
- 반복되던 FE 서버 다운의 원인을 찾아 NGINX로 전환, 이후 재발 0건
- 오픈마켓(쿠팡 등) 정책 위반 검증 기능 개발

**사용 기술** TypeScript, React, Vite, Tailwind CSS, TanStack Query, Zustand, React Native, NGINX

#### 1.2. 배포 전 QA 자동화 (테스트 시간 4시간 → 10분) (2026.02 ~ 2026.04)

배포 전 수동 회귀 QA 부담을 줄이기 위해 E2E 테스트 도입을 제안하고 주도했습니다.

**업무**

- Playwright 기반 E2E 테스트 설계, 구현
- QA 담당자와 함께 핵심 기능 중요도, 테스트 피로도를 고려해 자동화 우선순위 결정

**성과**

- 수동으로 4시간 넘게 걸리던 회귀 QA를 10분으로 단축

**사용 기술** Playwright, GitHub Actions

#### 1.3. 빌드 환경 개선 (빌드 시간 60% 단축) (2025.07 ~ 2025.08)

지원이 종료된 CRA에 쌓이던 보안, 성능, 호환성 문제를 해결하기 위해 진행했습니다.

**업무**

- CRA를 Vite로 전환하고, TypeScript 5, ESLint 9 함께 업그레이드
- 기능 코드 변경 없이 전환하고, 스프린트 초반 선배포로 검증 기간 확보

**성과**

- 배포 빌드 4분 30초 → 1분 50초 (약 60% 단축)
- 지원 중단으로 막혀 있던 보안 업데이트 적용 가능

**사용 기술** Vite, TypeScript, ESLint

#### 1.4. 상품 정보 추출 방식 개선 (2024.12 ~ 2026.06)

쇼핑몰 페이지 구조가 바뀌어도 상품 정보를 안정적으로 추출할 수 있도록 진행했습니다.

**업무**

- 알리익스프레스, 라쿠텐 등 주요 소싱몰을 HTML 대신 페이지 내부 데이터를 읽는 방식으로 전환
- Zod 런타임 검증으로 데이터 오류를 사전에 감지, 차단

**성과**

- 쇼핑몰 페이지가 바뀔 때마다 반복되던 긴급 대응이 거의 사라짐

**사용 기술** Chrome Extension, TypeScript, Zod
